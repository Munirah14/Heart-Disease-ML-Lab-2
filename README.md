# Heart-Disease-ML-Lab-2
Problem Definition:

Heart disease is one of the leading causes of mortality worldwide, and early detection plays a crucial role in reducing severe health complications and improving patient outcomes. However, diagnosing heart disease often requires multiple medical tests, which may be time-consuming and costly.

The objective of this project is to build a machine learning classification model that can predict whether a person has heart disease or not based on a set of clinical and demographic features. These features may include attributes such as age, gender, blood pressure, cholesterol level, heart rate, and other relevant medical indicators.

The problem is formulated as a binary classification task, where the target variable represents the presence or absence of heart disease:
1 → The patient has heart disease
0 → The patient does not have heart disease
